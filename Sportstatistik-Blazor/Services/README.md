# Services

Interface som sidorna anropar, och klasser som ni bygger.

- `ILeagueRepository` och `InMemoryLeagueRepository`: låtsasdatabasen. Ersätt den med er egen databasklass.
- `StandingsService`, `PositionService` och `SquadLimitService`: visar demodata eller kastar `NotImplementedException` tills ni byggt dem.
- `ResultFormatter`: fungerar redan, men fel med flit (önskemål 1).
